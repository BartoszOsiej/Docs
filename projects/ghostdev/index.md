# 💼 Ghost Developments — Website

**A Next.js 14 marketing site for Ghost Developments (Szczecin) — an IT
services business: portfolio, pricing, contact, and booking.**

---

## ✨ Features

| Feature | Description |
|---|---|
| **Portfolio** | Showcase of completed client work |
| **Pricing (cennik)** | Transparent service price list |
| **Contact (kontakt)** | Contact form & details |
| **Booking (rezerwacja)** | Appointment / order request flow |
| **Linux help (linux-help)** | Support article hub for Linux users |
| **Next.js App Router** | Modern file-based routing, RSC-ready |

## 🚀 Quick start

```bash
cd ghostdev
npm install
npm run dev        # http://localhost:3000
```
